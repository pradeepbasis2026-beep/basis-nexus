BASIS Fundamentals

SAP BASIS Architecture Explained

A simple practical introduction to the main components of an SAP ABAP system and how they work together.

What is SAP BASIS?

SAP BASIS is the technical administration layer that supports SAP applications. A BASIS administrator works across system availability, users and authorizations, transports, jobs, monitoring, performance, connectivity, upgrades and database-related activities.

Core components

1. ASCS – Central Services

The ABAP SAP Central Services instance provides the Message Server and Enqueue Server. The Message Server supports communication and load distribution between application servers, while the Enqueue Server manages SAP logical locks.

2. PAS – Primary Application Server

The PAS hosts SAP application services and work processes that execute user requests and business transactions.

3. AAS – Additional Application Server

AAS instances provide additional application capacity. Multiple application servers can distribute workload and improve scalability and availability.

4. SAP HANA Database

In modern S/4HANA landscapes, SAP HANA provides the database layer. The application servers communicate with HANA to read and write application data.

What does a BASIS administrator monitor?

  • System availability and SAP instances
  • Work processes and long-running requests
  • ABAP dumps using ST22
  • System log using SM21
  • Background jobs using SM37
  • Transports using STMS
  • Performance using ST03N and STAD
  • Database health and backups

Key takeaway

Think of the SAP landscape as three logical layers: users access the SAP application layer, application servers process the requests, and the HANA database stores and retrieves the business data. BASIS sits across these layers and keeps the environment secure, available, monitored and healthy.
