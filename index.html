Production playbook

Real-world scenarios & troubleshooting

A practical incident-first approach: identify the symptom, collect evidence, isolate the layer, fix safely, validate, and document the RCA.

P1 / CRITICALAvailability

SAP system is down

Users cannot log in or receive connection errors.

  1. Check OS/server availability and filesystem space.
  2. Run sapcontrol -nr <NN> -function GetProcessList.
  3. Check ASCS/PAS/AAS and database status.
  4. Review dev_disp, dev_ms, dev_w* and system logs.
  5. Restart only after identifying the failed component and following the runbook.
P1 / HIGHPerformance

SAP is suddenly very slow

Multiple users report high response time.

  1. Confirm scope and exact time window.
  2. Check ST03N for workload and response-time trends.
  3. Use STAD for request-level evidence.
  4. Check SM50/SM66, CPU, memory and DB indicators.
  5. Correlate with recent changes and infrastructure alerts.
HIGHTransport

Transport import failed — RC 8 / RC 12

A transport reaches QAS/PRD but the import ends with errors.

  1. Open the transport import log in STMS.
  2. Identify the exact object and error message.
  3. Check sequence/dependencies and target system status.
  4. Review relevant application logs or DDIC/object activation issues.
  5. Do not blindly re-import; document the cause and corrective action.
HIGHDatabase

HANA disk usage is critical

Database filesystem or HANA persistence usage is approaching capacity.

  1. Confirm which filesystem/volume is consuming space.
  2. Check HANA alerts and database usage.
  3. Review backup/log-backup destination growth.
  4. Do not delete database files manually.
  5. Engage the DB/storage owner and execute the approved cleanup/extension procedure.
MEDIUMJobs

Background job is cancelled

A business-critical SM37 job fails repeatedly.

  1. Check job log, job step and runtime.
  2. Check the executing user and authorization.
  3. Check ST22 if an ABAP dump occurred.
  4. Check SM50/SM66 and application logs if processing is stuck.
  5. Validate variant/input data before rerunning.
MEDIUMConnectivity

RFC connection fails

An interface reports a connection or authorization error.

  1. Test the destination in SM59.
  2. Separate network/host failure from authentication failure.
  3. Check gateway/service configuration where relevant.
  4. Validate technical user, certificate or password.
  5. Retest from SAP and confirm the dependent interface.
MEDIUMSecurity

SSL certificate is expired

An HTTPS integration suddenly stops working after certificate expiry.

  1. Confirm expiry and identify the affected PSE in STRUST.
  2. Obtain the correct certificate chain from the approved source.
  3. Update/import the chain according to the change procedure.
  4. Save/distribute the PSE as required.
  5. Retest the integration and document the new expiry date.
MEDIUMUsers

User cannot log in

A user reports password, lock, authorization or connection problems.

  1. Check whether the user is locked/expired in SU01.
  2. Separate authentication from authorization.
  3. Check ST22/application logs if a technical error occurs.
  4. For Fiori/SSO, check the identity provider/trust path.
  5. Never grant broad roles as a quick fix.
